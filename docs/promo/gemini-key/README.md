## The 16:9 cut

Landscape layout: the phone screen on the left in a live "screen window" (panning and
zooming with the narration), a 6-step progress rail on the right that ticks off as the
video goes, and burned-in subtitles at the bottom so it still works with the sound off.

```
python3 build_gemini_16x9.py                  # ~4-5 min, writes the 16:9 MP4
python3 build_gemini_16x9.py --stills 6,46    # check frames, no audio
python3 build_gemini_16x9.py --audio          # rebuild only the mix
python3 build_gemini_16x9.py --preview        # preview_16x9.jpg
```

- Voice: `vo16/v01_hook.mp3` … `v10_outro.mp3` (TTS, en-IN). Scene lengths are derived
  from the real clip durations, so re-recording a line and re-running the build re-times
  the whole video.
- Music: `../theme/kissa_theme_full.mp3` (our own theme, D harmonic minor, 43.6 s),
  looped with a 1.2 s equal-power crossfade, ducked to about −22 dB under the voice,
  plus `kissa_logo.mp3` as the end-card sting.
- Replacing the voice-over: drop new files into `vo16/` with the same names, run the
  build again.

## Values shown on screen (verify before publishing)

- Base URL: `https://generativelanguage.googleapis.com/v1beta/openai` (OpenAI-compatible
  layer; the `/v1` endpoint will 404 with Kissa's chat-completions client).
- Model: `gemini-3.8-flash` (free tier available at time of writing). Cheaper/lighter
  alternative shown in the caption: `gemini-3.5-flash-lite`.
- Free tier exists but content is used to improve Google's products; paid tier is not.

Google AI Studio pages are stylised illustrations of the public pages (marked
"Illustration of the public page" inside the video), and the Kissa screens are rebuilt in
the app's own layout (the screenshots on disk show a Groq provider, which would have been
wrong for this tutorial).
