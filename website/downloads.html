Website wali ginti: ek browser din mein ek baar "visitor" gina jaata hai (pehli baar aaya to "naya" bhi), aur Download button dabane wala din mein ek baar "download" gina jaata hai. Koi naam, IP ya ID save nahi hoti, sirf din-wise ginti. Ginti isi feature ke live hone ke din se shuru hui hai, bots nahi gine jaate, aur tum khud site kholo to tum bhi gine jaoge. Kisi din bahut zyada traffic aaye to server ki free limit bachane ke liye ginti ruk jaati hai; us din ke aage "+" dikhega (matlab asli number isse zyada hai).

GitHub wali ginti: website ka Download button, app ke andar update, ya releases page, har APK download gina jaata hai. Ek hi insaan do baar download kare to do gine jaate hain, aur tumhare apne test downloads bhi isme shaamil hain.
