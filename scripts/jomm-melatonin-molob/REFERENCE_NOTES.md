## What was rebuilt from scratch

The prior hard-edit renderer is not imported or modified. This build uses a new overscan base-cut pipeline and a new frame compositor:

- 33–39 shots per edit instead of the prior 8–11 long segments, quantized to the pinned audio beat clock.
- Per-cut directional camera kicks, rotational shake, punch zoom, pan drift and selected whip transitions.
- Selected musical impacts with procedural lightning, expanding shockwaves, horizontal glitch slices, RGB separation and radial speed lines.
- Seven character-specific colour-management profiles with deeper blacks, controlled highlight bloom and individual accent palettes.
- Procedural animated dust/energy particles.
- Three short, beat-placed kinetic typography moments per edit with extrusion, coloured rims, glow, overshoot entry and whip exit; no permanent top-left title card.
- Impact-aware review sheets that deliberately sample title and transition frames, plus full stream/frame-count/decode QA.

The result is an original production using the independently sourced anime footage. No Molob footage, project file, preset pack or rendered reference clip is included in the deliverable.
